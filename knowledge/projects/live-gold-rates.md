# Project — Live Gold Rates App

- **Type:** Professional / office — August 2023
- **Live:** <https://play.google.com/store/apps/details?id=com.kanhacraftjewels>
- **Stack:** React Native, Redux Toolkit, REST APIs

A cross-platform app for a jewellery business: real-time gold and silver
tracking, pricing calculations and catalog workflows.

- Released on Android and iOS.
- Live metal rates and pricing calculations.
- Administration and inventory features.
- Admin dashboard for rates, product catalogs and banners, so the business
  controls app content directly.
- Optimized state management and API usage with Redux Toolkit.
