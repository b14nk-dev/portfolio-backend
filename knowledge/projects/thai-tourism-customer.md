# Project — Thai Tourism Customer Site

Next.js 15 (App Router) booking site with roughly **110 routes**:

- **Commerce** — product, attraction, destination, package and tour pages;
  search, cart, checkout, confirmation, invoices.
- **Transport** — bus, ferry, cruise, taxi, airport transfers, car rental,
  eSIM and related services.
- **Account** — bookings, participants, reviews, wishlists, wallet, rewards,
  payment methods, profile and security.
- **Portals** — agent dashboard, wallet, invoices and booking tools; supplier
  application and status.
- **Content and trust** — help centre, FAQs, policies, blog and SEO pages.

Server components by default, per-page metadata and JSON-LD, ISR, image
optimization, Stripe Elements, Firebase push, React Hook Form with Zod,
Playwright end-to-end tests and Vitest unit tests.
