# FAQ — Projects

**Favourite project to discuss?** Fitclub Gym CRM — ~10,000 member records with
membership, attendance, billing and administration. I built the JWT/RBAC layer,
Razorpay payments and secure file uploads, and tuned the PostgreSQL queries for
a 35%+ dashboard gain. Largest system is Thai Tourism; deepest back office is
Fitclub.

**Personal vs professional?** Fitclub, Rishtey, Live Gold Rates and Thai Tourism
are professional office work. Quick Watch, the Terminal UI portfolio, the ASCII
Art Generator and this assistant are personal.

**Open-source contributions?** Public repos under github.com/b14nk-dev — an
Express server template, Rust CLI tools, a terminal system monitor and
JavaScript practice suites. My own projects, not contributions to other people's
projects.

**How would you explain Fitclub technically?** It is an Express API and
React/Vite operational dashboard for a gym business. I worked across member and
branch operations, attendance, billing, inventory, permissions, uploads and
reports, with PostgreSQL tuning that improved dashboard performance by 35%+.

**How would you explain the travel platform technically?** It is a two-app
product: a Next.js customer booking site and an Express/PostgreSQL CRM and API.
The system covers catalogue, pricing, inventory, carts, bookings, payments,
partners and operations, with versioned migrations, automated tests and
retry-safe external integrations.

**How would you explain Rishtey technically?** It is a Next.js and Express
matchmaking platform backed by MySQL and Sequelize. The work includes profile
onboarding and visibility, search and shortlists, subscriptions, PayU payment
callbacks, JWT/NextAuth sessions, OTP recovery, S3 media and performance work.

**What kind of engineering problems have you worked on?** My work has included
multi-step payment flows, webhook reliability, authorization, database and
query performance, media uploads, background jobs, migrations, testing and
operational dashboards. I can discuss the systems and trade-offs, but not
private code, credentials, internal endpoints or customer/partner details.

**What is Blind Chat?** It is a personal anonymous one-to-one chat project
using a Next.js frontend and an Express/Socket.IO backend. It demonstrates
real-time bidirectional events and client/server coordination without making
claims about production scale.

**What is your Node and Express template?** It is a personal JavaScript
template that experiments with dynamic route registration, route metadata and
centralized asynchronous error handling. It reflects my API-structure ideas,
not a production client system.

**What is better-cd?** It is a personal Rust command-line tool that replaces
the usual directory-jump workflow with named persistent bookmarks, optional
directory creation and shell integration backed by an embedded database.
