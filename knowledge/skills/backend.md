# Skills — Backend and APIs

Node.js/Express REST services and modular architecture; JWT/httpOnly-cookie
auth, OAuth (Google, Facebook, Apple, Twitter, LINE, Kakao), RBAC and permission
middleware; webhooks, idempotency and third-party orchestration.

Payments: Stripe manual capture, PayPal, PayU and Razorpay. Security/reliability:
CSRF, rate limits, correlation IDs, audit logs, Helmet, Pino and redaction.

Data and delivery: Sequelize associations/transactions, scoped queries,
SQL-first release-gated migrations, caching, request de-duplication, scheduled
jobs, Nodemailer, S3/presigned uploads and Sharp image processing.

Validation: Zod, express-validator, Yup. Testing: `node:test`, Vitest and
Playwright. Production backend is JavaScript/TypeScript; Python/FastAPI is only
this assistant.
