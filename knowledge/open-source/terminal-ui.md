# Open Source — Binaire-FreznelAI-Assessment

<https://github.com/b14nk-dev/Binaire-FreznelAI-Assessment> ·
TypeScript, OpenTUI, Firebase Auth

A `btop`-style terminal system monitor: collectors for CPU, memory, disk,
network and processes; login, sign-up, dashboard and settings screens; Firebase
auth with refresh-token persistence; reusable header, footer, panel, graph and
process-table components.

Shows terminal UI rendering, real system metrics and auth session handling
outside the browser.
