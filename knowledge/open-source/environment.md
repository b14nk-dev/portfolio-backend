# Open Source — Environment and Configuration

## nvim-config

<https://github.com/b14nk-dev/nvim-config> · Lua

Personal Neovim config: per-language LSP setup (bash, emmet, HTML, JSON, Lua,
marksman, Python, Rust, Tailwind, TypeScript), `mini.nvim` modules, `conform`
formatting, `mason` tool installation, custom statusline and terminal handling.

## cachyOS-setup

<https://github.com/b14nk-dev/cachyOS-setup> · Shell, Lua, C, Python, JavaScript

Arch/CachyOS dotfiles and tooling: `dwm` config and patches, Alacritty and
Helix configs, shell helpers (`amt`, `aphone`, `dsa`, `furl`, `qb`, `rec`) and a
packaged `keypress-sound` binary. Large because it vendors configuration, not
because it is one program.

## personal-bash-scripts

<https://github.com/b14nk-dev/personal-bash-scripts> · Shell

Small scripts (`create_brave.sh`, `gitclone`).
