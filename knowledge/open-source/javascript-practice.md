# Open Source — JavaScript Practice

Both repos are test-driven practice with a shell test harness.

## shipthatcode-js-fundamentals

<https://github.com/b14nk-dev/shipthatcode-js-fundamentals> · JavaScript

15 fundamentals: hello world, variables, numbers, strings, template literals,
conditionals, loops, functions, arrow functions, arrays, objects,
map/filter/reduce, destructuring, equality/coercion and ES modules.

## shipthatcode-js-intermediate

<https://github.com/b14nk-dev/shipthatcode-js-intermediate> · JavaScript

15 intermediate topics: block scope and hoisting, closures, IIFE/module
pattern, promises, async/await, promise patterns, `this`, prototype chain,
try/catch/throw, custom error classes, iterators and generators, regular
expressions, Set/Map, property descriptors and dynamic modules.

Shows deliberate depth in JavaScript semantics, not just frameworks.
